HOW TO READ THIS

One glance first. Detail only when needed.

01
Position = time

A block near the top happened at night; lower blocks happened later in the day.

02
Size = duration

Taller blocks lasted longer. Tiny blocks remain available through hover, focus, or the detail list.

03
Colour = threat level

Yellow marks a drone warning; red marks a high-level threat. Blue-grey means classification was unavailable.

04
Shaded band = 09:00–18:00

The background band shows the daytime work window without changing the threat colour.

Data source: configured alert API Live classification · historical intervals supplemented by Kyiv Digital
Intervals crossing midnight are split across calendar days. Durations are recalculated from timestamps. Unclassified history stays blue-grey rather than being guessed. This dashboard is informational and is not an official warning channel.
